# Going Dutch

Expense-splitting app for friends and groups. All data stays in your browser — no backend, no account.

## Tech

Vite + React 18 + TypeScript + shadcn/ui + Tailwind CSS. Deployed to Cloudflare Pages.

## Setup

```sh
npm install
npm run dev      # starts on port 8080
npm run build    # production build
npm run lint     # ESLint check
npm run preview  # preview production build
```
